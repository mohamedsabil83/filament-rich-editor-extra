The plan of this package is to provide a set of extra extensions for [Filament RichEditor](https://filamentphp.com/docs/4.x/forms/rich-editor).

## Installation

You can install the package via composer:

```bash
composer require mohamedsabil83/filament-rich-editor-extra
```
